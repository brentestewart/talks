Slide 3

The first new level of abstraction in 65 years

  • Machine code (1940s) · Assembly (1950s) · High-level languages (1957) · Natural language (2022)
  • Most change is constant motion; this is a shift in how we create software
  • Machine code: plugboards, then toggle switches one bit at a time
  • Assembly: words instead of numbers; the assembler was the first time software wrote software
  • FORTRAN: "you wrote the formula, the compiler figured out the steps"; punched cards (80 columns)
  • LLMs: describe the what, not the how. Karpathy: "The hottest new programming language is English"
  • If challenged: 4GLs and Prolog tried, but none changed how most developers write code

Slide 7

What I've learned the hard way

  • It ignores instructions
  • It goes down rabbit holes (commit often)
  • It guesses when you're vague
  • It's confidently wrong
  • It's only as good as its context
  • It tells you what you want to hear
  • Trust: like assembly to FORTRAN, we can't read everything, and LLMs aren't deterministic, so trust comes from tests, static analysis and specs

If I were starting today
