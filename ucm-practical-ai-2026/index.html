When does AI actually fit?

"Should it always act this way?"

If yes, it's just software.

  • Is the input messy or unstructured?
  • Is "mostly right" acceptable, or can a person review it?
  • Would a rule or formula do the job?

What to do next

  1. Work on a passion project. Intern somewhere or start a real app. Learn the whole SDLC with best practices and build a resume with actual code.
  2. Review open source projects. See how they organize code and set up unit tests.
  3. Connect with people in your target industry. Find a mentor.

What to learn along the way

  • Source control: branches, pull requests, good commits
  • Writing a spec before you build
  • Project structure and architecture
  • Testing: unit and integration
  • CI/CD: automated build, test, deploy
  • Deploying something people can use
  • Security basics: secrets, authentication
